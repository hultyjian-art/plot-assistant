# 剧情推进助手

一个酒馆助手（Tavern Helper）脚本：**在发送消息前自动跑一轮剧情推进，把结果包进这条消息里**，让 AI 写正文时有明确的剧情方向，而不是自由发挥。

---

## 一句话说明

你点发送 → 脚本先拿你这句话、前几轮的 AI 输出、世界书、数据库表格，跑一批 AI 任务（召回哪些旧剧情、该补哪些设定），把这些结果整理成一段指令塞回你这条消息 → 正文 AI 拿着这段指令写故事。

**它不是替 AI 写正文，是给正文 AI 递剧本。**

---

## 安装

酒馆助手脚本区里新建一个脚本，内容只填下面这一行：

```javascript
import 'https://cdn.jsdelivr.net/gh/hultyjian-art/plot-assistant@v1.0.8/dist/plot-assistant/index.js'
```

刷新酒馆，脚本会自己装上。

> 链接里的 `@v1.0.8` 是版本号。**更新时只改这个数字**（比如换成 `@v1.0.9`）就能拉到新版本，文件路径永远不变。

---

## 它做什么

| 功能 | 说明 |
|---|---|
**剧情推进** | 发送前跑一轮 AI 规划，把结果注入这条消息 |
**捕获链** | 按你排的顺序逐条正则尝试，从楼层里取出要用的文本 |
**AI 楼层模式** | 从「最新用户楼层上方的 AI 楼层」取文，而不是从用户那句话 |
**全流程重刷** | 取出文本 → 删掉楼层 → 替你按下发送，一步到位 |
**回填修改** | 只把捕获到的文本填回输入框，一个 AI 请求都不发 |
**手势绑定** | 单击 / 双击 / 长按 / 三击 / 右键，各自绑一个动作 |
**暂存** | 一次推进没全跑完时，已完成的成果先存着，重发时只补没完成的任务 |

---

## 用法

脚本装上后，在酒馆的**脚本按钮区**（QR 区）会出现一个叫「推进重刷」的按钮。

默认手势：

| 手势 | 动作 |
|---|---|
| 单击 | 打开设置 |
| 双击 | 原生重刷（等同酒馆自己的「重新生成」） |
| 长按 450 毫秒 | 回填修改（把文本捞回输入框，不发请求） |
| 三击 | 全流程重刷 |
| 右键 | 回填修改 |

**这些都能在设置页里改。** 也可以从魔法棒菜单里点「剧情推进助手」直接打开设置。

## 世界书与上下文：哪些条目不会发给 AI

设置页「世界书（$1）」决定剧情推进那一轮 AI 能读到哪些世界书内容。酒馆这轮激活的条目里，下面几类**不会**发给剧情推进 AI：

| 类别 | 怎么认 | 为什么 |
|---|---|---|
| 名字带屏蔽词 | 名字里出现：思维链、cot、MVU、mvu、变量、状态、Status、Rule、rule、检定、判断、叙事、文风、InitVar、格式 | 这些多半是给 MVU 变量框架、正则、状态栏用的条目，正文常是变量定义或格式说明，AI 读了只会照着写代码 |
| 大纲表 / 纪要索引 | 数据库生成的大纲表、纪要索引条目 | 它们有专用占位符，不在这里重复展开 |
| 脚本自己写的条目 | 名字以 `plot_assistant-` 开头 | 标签块写进世界书后，任务提示词里已有 `{{标签}}`，再展开一遍就重复了 |

两个容易踩的点：

- **中文「规则」不在屏蔽词里**——「王国规则总览」这类正经设定条目能正常发给 AI。但英文 `Rule` / `rule` 在名单里，`Kingdom Rule Overview` 仍会被排除。想让条目进来，给它换个不带这些字的名字即可。
- 数据库脚本生成的条目**会**进 $1，只有 $9 这个占位符会剔除它们。

设置页的条目列表里，会被自动排除的条目会标上「自动排除」，勾不勾都不影响生成。以当前这一版的设置为准。

## 依赖

**需要装「龙血玄黄·数据库」（ACU）脚本。**

剧情推进要从数据库读世界书、表格、纪要索引这些内容。没装 ACU 的话，剧情推进这一块拿不到数据；只用手势重刷、捕获回填这些功能仍然可用。

## 自己改 / 二次开发

```bash
pnpm install
pnpm build
```

产物在 `dist/plot-assistant/index.js`。文件名固定不变，版本靠 git tag 区分。

目录结构：

```
src/plot-assistant/
├─ index.ts          入口（声明显示名与按钮名，然后启动）
└─ modules/          全部实现
   ├─ actions.ts     重刷流程（捕获 / 删层 / 发送）
   ├─ gesture.ts     手势识别
   ├─ regex.ts       捕获链
   ├─ settings.ts    设置读写与校验
   ├─ settings-panel/ 设置面板（Vue）
   └─ plot/          剧情推进引擎
```

想改行为，大部分情况下改 `modules/` 下对应的文件就行，`index.ts` 基本不用动。
